## Batch folders

The main working files for this batch are under [`docs/mapp_project_00084/mapp_batch_00268/`](docs/mapp_project_00084/mapp_batch_00268/).

- [`results/met_annot_enhancer/`](docs/mapp_project_00084/mapp_batch_00268/results/met_annot_enhancer/): metabolite annotation enhancement outputs.
- [`results/metaboanalyst/`](docs/mapp_project_00084/mapp_batch_00268/results/metaboanalyst/): MetaboAnalyst-ready files and outputs.
- [`results/mzmine/`](docs/mapp_project_00084/mapp_batch_00268/results/mzmine/): MZmine batch files and processing outputs.
- [`results/sirius/`](docs/mapp_project_00084/mapp_batch_00268/results/sirius/): SIRIUS/CSI:FingerID outputs.
- [`results/stats/`](docs/mapp_project_00084/mapp_batch_00268/results/stats/): statistical analysis outputs.
- [`results/xcalibur/`](docs/mapp_project_00084/mapp_batch_00268/results/xcalibur/): Xcalibur exports and related files.
- [`report/`](docs/mapp_project_00084/mapp_batch_00268/report/): rendered or intermediate report files.
